# Put the reference image here

Copy one AI-generated reference image into this directory as `reference.png`,
`reference.jpg`, `reference.jpeg` or `reference.webp`, then run:

```bash
make setup
make all
```

The input remains a reference only. It is never embedded in the final SVG.
Do not commit confidential or unpublished source images unless you intend to
share them with everyone who can read the repository.

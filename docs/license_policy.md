# 素材许可证记录规则

## 默认优先级

1. Public Domain / CC0：通常最简单，但仍保留来源页面和 hash。
2. MIT / ISC / Apache 2.0：保留许可证文本或链接及版权声明。
3. CC BY / CC BY-SA：保留作者、来源和许可证；CC BY-SA 的衍生作品要遵守相应分享条款。
4. 其他条款：逐项确认是否允许论文、补充材料、商业出版和修改。

## 需要谨慎的来源

- NC（NonCommercial）可能不适用于商业出版、基金项目或商业期刊服务；
- ND（NoDerivatives）不适合需要改色、裁剪、组合或重构的素材；
- 平台写着“free”不代表文件有统一开源许可；SVG Repo、Openverse、Iconify 等要回到单个文件的原始来源页；
- BioRender、The Noun Project、Flaticon 和部分 OpenStax 内容可能受订阅、署名或非商业条款限制。

## 每个素材要记录

使用 [`asset_manifest_template.csv`](asset_manifest_template.csv) 记录：来源 URL、作者、许可证名称和 URL、下载日期、原始文件 SHA-256、修改方式、最终文件中的用途和署名文本。示例 Panel A 的记录在 [`asset_manifest_panel_a_v02.csv`](asset_manifest_panel_a_v02.csv)。

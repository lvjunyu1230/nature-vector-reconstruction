# Asset source registry

This catalog is a starting point for finding reusable geometry. Always verify the individual file page, license version, attribution requirement and publication/commercial terms before redistribution.

## Scientific object sources

| Source | Link | License | Best for | Notes |
|---|---|---|---|---|
| Bioicons | [Bioicons](https://bioicons.com/) | Per asset: CC0, CC BY, CC BY-SA, MIT and others | biology, chemistry, lab objects, animals, plants | Check the individual icon page; preserve attribution for CC BY/SA |
| Servier Medical Art | [Servier Medical Art](https://smart.servier.com/) | CC BY 4.0 | medical, anatomy, biological objects | Attribution required |
| Reactome Icon Library | [Reactome Icon Library](https://reactome.org/icon-lib) | CC BY 4.0 | molecular, cellular and pathway symbols | Attribute CSHL, OICR and EBI |
| PhyloPic | [PhyloPic](https://www.phylopic.org/) | Per silhouette; includes Public Domain, CC BY, CC BY-SA and NC variants | organism silhouettes | Use the Public Domain filter where possible |

| OpenClipart | [OpenClipart](https://openclipart.org/) | CC0 / public domain | generic objects and simple scenes | Keep the item page and author record |

| LibreClipart | [LibreClipart](https://libreclipart.org/) | CC0 per platform statement | generic clipart | Keep source metadata |
